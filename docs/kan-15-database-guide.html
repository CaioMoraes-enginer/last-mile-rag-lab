Ideia central

Três responsabilidades, sem mistura.

Separar as camadas deixa o projeto testável, reproduzível e fácil de evoluir.

1

Docker executa

Cria um ambiente isolado com PostgreSQL, pgvector, volume persistente e healthcheck.

2

Repository conversa

Centraliza inserts, upserts e buscas. O restante do Python não espalha SQL pelo projeto.

3

Loader transporta

Lê o artefato da ingestão e pede ao repository para persistir cada chunk com segurança.

Carga de dados

Loader: transporta sem decidir.

Ele não cria chunks nem gera respostas. Lê o artefato, valida cada linha e chama o repository.

A

Ler JSONL

Uma linha JSON por chunk facilita streaming, auditoria e reprocessamento.

B

Falhar com clareza

Linha inválida informa arquivo e número. Uma carga parcial não parece completa.

C

Reexecutar

O mesmo arquivo pode ser recarregado: o upsert atualiza IDs existentes.

Importante: enquanto a KAN-6 não gera o artefato real, o KAN-15 usa uma fixture representativa. A interface fica pronta para receber a saída futura.
Recuperação híbrida

O mesmo banco, três maneiras de encontrar evidência.

Clique nas opções para comparar entrada, operação e uso.

Busca vetorial

Entrada: embedding da pergunta. Operação: distância cosseno com <=>. Saída: chunks semanticamente próximos.

SELECT chunk_id, embedding <=> :query_vector AS distance
FROM chunks
WHERE embedding IS NOT NULL
ORDER BY distance ASC
LIMIT 5;

Busca lexical

Entrada: texto ou ID exato. Operação: tsvector. Saída: chunks com termos como ORD-042 ou SG-BD.

SELECT chunk_id, content
FROM chunks
WHERE content_tsv @@ plainto_tsquery('portuguese', 'SG-BD');

Filtros estruturados

Entrada: zona, versão e instante. Operação: condições SQL determinísticas. Saída: evidências compatíveis.

WHERE zona = 'ZONA-03'
  AND effective_from <= :decision_at
  AND (effective_to IS NULL OR effective_to >= :decision_at)
Infraestrutura

Por que colocar o banco no Docker?

Docker não é o banco. É a embalagem reproduzível que executa o banco e suas dependências.

Mesmo ambiente

A imagem fixa PostgreSQL + pgvector. Outra pessoa não configura a extensão manualmente.

Isolamento

O serviço usa porta, variáveis, rede e volume próprios.

Produção em miniatura

Healthcheck, persistência e rede imitam padrões reais, sem fingir alta disponibilidade ou backups.

docker compose up -d
python -m db.smoke_test
python -m db.repository_smoke_test
